# Frontend Mentor - QR code component

This is a solution to the QR code component challenge on Frontend Mentor. Frontend Mentor challenges help you improve your coding skills by building realistic projects.

## Overview

### The challenge

Users should be able to:

View the optimal layout for the component depending on their device's screen size.

See a card component precisely sized at 375px by 812px to match specific design requirements.

### My process

Built with
Semantic HTML5 markup for a meaningful structure.

CSS Custom Properties: Utilized variables for consistent coloring like --color-bg and --color-hd.

Flexbox: Applied display: flex on the body and containers to handle perfect centering.

Mobile-first workflow: Optimized the layout for mobile viewports using relative units and specific dimensions.

### What I learned

During this project, I focused on managing exact dimensions while maintaining a clean layout. I implemented a specific card size of 375px by 812px.

One key takeaway was using box-sizing: border-box to ensure padding doesn't affect the final width of the element:

I also practiced using the Outfit font family from Google Fonts to match the design's typography.
